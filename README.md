# FloatSnip · 浮球快贴

> 一个随时外显的悬浮球，点一下就复制你常用的文字。免费、开源、单文件、免安装。

## 为什么需要它

复制粘贴是日常最高频、也最打断心流的操作之一：

- 写代码时要反复从别处复制 prompt / 常用片段，来回切换窗口、选中、复制；
- 发弹幕、聊天话术、账号、命令模板……任何「常用语」都在重复「找→选→复制→粘贴」；
- 市面上的片段工具要么太重（整个 App），要么要联网登录，要么分发混乱。

**FloatSnip 想做的很简单：让常用文字「就在指尖」——一个浮球，点开就看到，点一下就复制，完了。**

## 功能

- **悬浮球 · 随时外显，可拖动**：小球常驻桌面最上层，按住直接拖到任意位置；点一下顺滑展开成面板。
- **快捷键召唤 · 可自定义**：默认 `Ctrl + `` ` `` 随时唤起/收起；在设置里点一下快捷键框、按下你想要的组合键即可更换（如 `Ctrl+Alt+B`），改完立即生效并记住。
- **列表即首页**：展开第一眼就是全部常用语，可滚动；点任意一条 → 自动复制 → 弹「复制成功」。
- **分类标签**：顶部标签切换（默认「所有」，可自建最多 5 个分类，如 AI / 平常常用），想看哪类看哪类。
- **随手编辑**：底部「＋ 新建常用语」随时加；每条目带 ✎ 编辑、✕ 删除；内容支持中文输入法，无硬上限（软上限 10000 字）。
- **可不显示**：点面板标题栏的 ▁，或设置里「隐藏悬浮球」，浮球立即消失；按快捷键随时唤回。
- **纯本地 · 零账户**：所有内容存在本机 `AppData\Local\FloatSnip\data.json`，你拥有、可改、可同步，不上传任何服务器。
- **可选自动粘贴**：在设置里开启后，复制完自动向刚才的窗口粘贴（实验性）。
- **开机自启**：设置里一键开启，开机后自动出现在桌面。

## 使用方法

1. 下载 `FloatSnip.exe`，双击运行（无需安装）。
2. 桌面出现一个小圆球：**按住它拖动**到顺手的位置；点击它（或按 `Ctrl + `` ` ``）展开面板。
3. 点面板里的任意常用语 → 已复制，去目标处 `Ctrl + V` 即可。
4. 点「＋ 新建常用语」添加你自己的内容；点条目的 ✎ 可修改、✕ 可删除。
5. 顶部标签切换分类；设置（⚙）里可以：改快捷键、开关自动粘贴、开关开机自启、隐藏浮球、改名分类、退出。

> 数据文件位置：`%AppData%\Local\FloatSnip\data.json`（可直接备份或编辑）。

## 技术

- 后端 Python：全局热键、剪贴板、本地存储。
- 前端 Web（HTML/CSS/JS），经 [pywebview](https://github.com/r0x0r/pywebview) 承载于系统 Edge WebView2。
- 打包为单文件 exe，目标 Windows 10 / 11（需系统自带 WebView2，通常已预装）。
